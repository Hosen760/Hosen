## 1.1 建设目标

投研团队每天会产生大量资料：

- 项目BP
- 基金季度报告
- 财务尽调报告
- 法务尽调文件
- 专家访谈纪要
- 行业研究报告
- 投后经营数据
- 投委会材料
- 内部投资复盘
- 制度规则文件

因此，本系统要做四件事：

| 目标      | 说明              |
| ------- | --------------- |
| 资料集中存储  | 所有原始文件统一存放，避免散落 |
| 知识结构化   | 把原始资料整理成标准化笔记   |
| AI可检索问答 | 用户通过飞书Bot直接提问   |
| 来源可追溯   | 每个回答都能看到引用了哪些文件 |

## 1.2. 系统整体架构

系统分为四层：

```text
                                    Internet
                                       │
                        ┌──────────────┴──────────────┐
                        ▼                             ▼
              飞书API / MiniMax API            Syncthing Relay
                    (外网中转)                    (外网中转)
                        │                             │
┌───────────────────────▼─────────────────────────────▼───────────────────────┐
│                                局域网路由器                                   │
└──────────┬───────────────────────────┬───────────────────────────┬──────────┘
           │                           │                           │
           ▼                           ▼                           ▼
┌────────────────────┐      ┌────────────────────┐      ┌────────────────────┐
│      用户电脑      │      │     Mac Studio     │      │      群晖 NAS      │
│                    │      │     (15+ Users)    │      │     (存储中心)     │
│  Syncthing 客户端  │      │  Supervisor / Agent│      │   全量知识库 RAID5 │
└──────────┬─────────┘      └──────────┬─────────┘      └──────────┬─────────┘
           │                           │                           │
           └───────────────────────────┼───────────────────────────┘
                                       ▼
                          Syncthing 三方实时双向同步

──────────────────────────────────────────────────────────────────────────────
【业务数据流】
 用户飞书提问 ──> 飞书Bot ──> 路由转发 ──> Mac Studio (专属 Agent 业务处理与响应)

```

### 📊 架构说明

| 层级                        | 组件名称             | 核心配置 / 技术栈                                  | 业务定位与核心职责                        |
| ------------------------- | ---------------- | ------------------------------------------- | -------------------------------- |
| **外网接入层**<br>(Internet)   | 飞书 / MiniMax API | 开放平台 API 接口                                 | 负责对接外部大模型能力及飞书应用端，实现消息收发。        |
|                           | Syncthing Relay  | 外网中转服务器                                     | 在跨网段或无公网 IP 情况下，提供数据同步的安全穿透与中转。  |
| **网络传输层**<br>(LAN)        | 局域网路由器           | 本地千兆/万兆网络                                   | 作为本地数据传输枢纽，保障高带宽、低延迟的本地数据交互。     |
| **本地核心层**<br>(Core Nodes) | 用户电脑             | Syncthing 客户端                               | 员工日常工作终端，参与本地知识库文件的实时双向同步。       |
|                           | Mac Studio       | 15+ 智能体并发<br>Supervisor 进程管理<br>专属 AI Agent | 系统算力中心：运行 Agent 智能体，处理飞书提问并进行推理。 |
|                           | 群晖 NAS           | 全量知识库<br>RAID 5 磁盘阵列                        | 系统存储中心：安全存储全量知识库，提供高可靠的数据冗余保护。   |
